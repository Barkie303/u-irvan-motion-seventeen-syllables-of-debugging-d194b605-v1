A haiku about debugging, in the 5-7-5 syllable shape. The program writes it to `/output/entry.txt`.

```
The breakpoint holds still
the logs all swear nothing changed
it was my typo
```

Seventeen syllables: 5 + 7 + 5. The breakpoint holds, the logs insist nothing changed — and the last line turns the poem: the bug was one keystroke of my own.
